# Task Automation System (Python)

Sistema de automação de tarefas desenvolvido em Python para automatizar atividades repetitivas no computador.

## 🚀 Funcionalidades

- 📁 Organização automática de arquivos por tipo
- 📝 Renomeação automática de arquivos
- 🌐 Download de páginas da web
- 📧 Envio automático de e-mails

## 🛠 Tecnologias utilizadas

- Python
- Biblioteca os
- Biblioteca shutil
- Biblioteca requests
- Biblioteca smtplib
